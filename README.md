# Сервер мониторинга качества дорог

Сервер для сбора и анализа данных о качестве дорог с мобильных устройств, обнаружения ям и визуализации результатов на интерактивных картах.

## Возможности

- 📱 Сбор данных с мобильных устройств (GPS + акселерометр)
- 🕳️ Алгоритм обнаружения ям
- 🗺️ Интерактивные карты с использованием Folium
- 📊 Хранение данных в SQLite базе
- 📧 Уведомления по email (запуск, ошибки, остановка)
- ⏱️ Периодическая обработка данных

## Технологии

- Python 3.7+
- aiohttp (асинхронный веб-сервер)
- aiosqlite (асинхронная работа с БД)
- pandas (анализ данных)
- folium (визуализация карт)
- smtplib (email уведомления)

Сервер автоматически обрабатывает данные каждые:
4 часа: Обнаружение ям (reseah_hole())
6 часов: Генерация карт (create_map_hole())
Сгенерированные карты сохраняются в:
map_hole.html - Общая карта всех ям
maps_users/{user_id}/ - Персональные карты пользователей
